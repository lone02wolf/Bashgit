# BashGit

BashGit Labs website built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, Lenis, and Lucide Icons.

## Local development

```sh
npm ci
npm run dev
```

Open http://localhost:3000. Validation: `npm run lint` and `npm run build`
(the production build also checks TypeScript).

The redesign is being reviewed in phases. See [Phase 1 design foundation](docs/design-foundation.md)
for reference research, font comparison, tokens, reusable primitives and scope.
See [contact setup](docs/contact-setup.md) before changing email delivery settings.
